# 高血脂（高脂血症）饮食建议

> 本文依据国家卫生健康委《成人高脂血症食养指南（2023年版）》整理，面向成人高脂血症人群日常膳食参考。有合并症者应在医师或营养指导人员指导下制定个性化方案。

## 核心原则

指南对高脂血症人群的日常食养提出 8 条原则和建议（来源：成人高脂血症食养指南2023）：

1. **吃动平衡，保持健康体重。** 在满足每日必需营养的基础上控制能量摄入、维持健康体重、减少体脂；超重和肥胖人群应通过控制能量摄入减重。
2. **调控脂肪，少油烹饪。** 限制总脂肪、饱和脂肪、胆固醇和反式脂肪酸的摄入，减少油炸、油煎，多选蒸、煮。
3. **食物多样，蛋白质和膳食纤维摄入充足。** 选择平衡膳食模式，适当选择低脂动物蛋白、提高大豆蛋白摄入，多吃全谷物、杂豆、蔬菜等富含膳食纤维的食物。
4. **少盐控糖，戒烟限酒。** 培养清淡口味，控制盐和添加糖，完全戒烟并避免二手烟，提倡限制饮酒。
5. **因人制宜，辨证施膳。** 根据年龄、性别、体质、生活习惯辨别中医证型，给予个性化食养方案。
6. **因时制宜，分季调理。** 春季护阳保肝、初夏益气清心、长夏清利湿热、秋季滋阴润肺、冬季散寒补肾。
7. **因地制宜，合理搭配。** 根据北方、南方、西北、青藏不同地区的气候与体质差异调整膳食。
8. **会看慧选，科学食养，适量食用食药物质。** 通过营养标签选择低脂肪、低钠食品，适量摄入富含植物甾醇的食物及符合规定的食药物质。

## 量化速查

以下数字均出自《成人高脂血症食养指南（2023年版）》原文（来源：成人高脂血症食养指南2023）。

### 一、能量、体重与运动

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 超重、肥胖人群每日减少能量摄入 | 300～500 kcal |
| 超重、肥胖人群减重目标 | 体重减少 10% 以上 |
| 体育锻炼频率 | 每周 5～7 次 |
| 每次运动时长 | 30 分钟中等及以上强度 |
| 每日锻炼消耗能量 | 至少 200 kcal |
| 食谱示例每日能量范围 | 1700～1900 kcal |

### 二、脂肪与油

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 脂肪供能占总能量 | 20%～25% |
| 以每日 1800～2000 kcal 计，全天脂肪总量 | 40～55 g（含烹调油、动物性食品及坚果等油脂） |
| 每日烹调油 | 不超过 25 g |
| 饱和脂肪供能占总能量 | ＜10%；高胆固醇血症者 ＜7% |
| 每日胆固醇摄入 | ＜300 mg；高胆固醇血症者 ＜200 mg |
| 反式脂肪酸供能占总能量 | ＜1%，即每天不超过 2 g |

### 三、碳水、膳食纤维与食物种类

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 碳水化合物供能占总能量 | 50%～60% |
| 以每日 1800～2000 kcal 计，全天碳水化合物 | 225～300 g |
| 每日膳食纤维 | 25～40 g（其中水溶性膳食纤维 7～13 g） |
| 每日食物种类 | 不少于 12 种 |
| 每周食物种类 | 不少于 25 种 |
| 每日植物甾醇摄入 | 2 g 左右 |

### 四、蔬菜、水果、大豆与奶

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 每日新鲜蔬菜 | 500 g，深色蔬菜占一半以上 |
| 每日新鲜水果 | 200～350 g |
| 每日大豆蛋白 | 含 25 g 大豆蛋白的食品 |
| 奶类选择 | 脱脂或低脂牛奶、低糖酸奶 |

### 五、盐、糖与烟酒

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 每日食盐 | 不超过 5 g |
| 添加糖供能占总能量 | 不超过 10%；肥胖和高甘油三酯血症者应更低 |
| 饮酒 | 提倡限制饮酒；即使少量饮酒也可使高甘油三酯血症人群甘油三酯进一步升高 |
| 吸烟 | 完全戒烟，有效避免吸入二手烟 |

### 六、血脂异常诊断切点（空腹静脉血清）

| 指标 | 异常切点 |
| --- | --- |
| 总胆固醇（TC） | ≥5.2 mmol/L |
| 甘油三酯（TG） | ≥1.7 mmol/L |
| 低密度脂蛋白胆固醇（LDL-C） | ≥3.4 mmol/L |
| 高密度脂蛋白胆固醇（HDL-C） | ＜1.0 mmol/L |

## 推荐膳食模式

指南明确提出的膳食模式与搭配原则如下（来源：成人高脂血症食养指南2023）：

- **平衡膳食模式。** 在控制总能量及脂肪的基础上，选择食物多样的平衡膳食模式，主食定量、蔬果丰富、肉类适当；适当控制精白米面，增加全谷物、杂豆类。
- **少油烹饪。** 少用油炸、油煎，多选蒸、煮；烹调油优先选择紫苏油、亚麻籽油、核桃油、橄榄油、茶籽油、菜籽油、葵花籽油、玉米油、芝麻油、豆油、花生油等，减少棕榈油、椰子油及猪油、牛油、羊油等动物油。
- **低脂蛋白搭配。** 动物蛋白选鱼虾类、去皮禽肉、瘦肉；奶类选脱脂或低脂奶；提高大豆蛋白摄入；少吃肥肉、加工肉制品、鱼籽、蟹黄、鱿鱼、动物内脏。
- **中医辨证施膳。** 按痰浊内阻、痰瘀互结、气滞血瘀、气虚血瘀、肝肾阴虚、脾虚湿盛 6 种证型分别搭配食养方与茶饮。
- **分季、地域调整。** 春季多食时令蔬菜并佐以疏肝食药物质；长夏清淡健脾化湿；秋季滋阴润肺；冬季温补肾阳；北方侧重祛湿化痰、南方侧重益气健脾、西北减少牛羊肉、青藏增加去皮禽肉与大豆蛋白。

> 说明：本指南原文未直接使用"DASH 饮食""东方健康膳食模式"等命名，仅提出"平衡膳食模式"及上述辨证、分季、因地搭配原则。

## 常见误区

1. **误区：血脂高就必须完全忌油、忌肉、忌蛋。**
   指南要求的是"调控脂肪、少油烹饪"，并非完全无油无肉。每日烹调油不超过 25 g、脂肪占总能量 20%～25% 即可；蛋类（鸡蛋、鸭蛋）仍在推荐食物名单内，动物蛋白优先选鱼虾、去皮禽肉、瘦肉，胆固醇每日控制在 300 mg（高胆固醇血症者 200 mg）以内，而非一刀切禁食。（来源：成人高脂血症食养指南2023）

2. **误区：植物油健康，可以多放、随便吃。**
   无论植物油还是动物油，都计入全天脂肪总量。指南规定全天脂肪（含烹调油、动物性食品及坚果）应控制在 40～55 g，每日烹调油不超过 25 g；棕榈油、椰子油即使是植物油也被列入减少、限制品种。（来源：成人高脂血症食养指南2023）

3. **误区：吃素、吃粗粮就能自动降血脂，不用控制总能量和糖。**
   指南强调碳水化合物仍占总能量 50%～60%，且添加糖不应超过总能量 10%；即使全谷物、薯类也需按能量定量。蛋白质摄入不足反而不利，应保证鱼虾、去皮禽肉、瘦肉及大豆蛋白充足。（来源：成人高脂血症食养指南2023）

4. **误区：少量饮酒"活血""软化血管"，对高血脂无妨。**
   指南明确指出：即使少量饮酒也可使高甘油三酯血症人群甘油三酯水平进一步升高，因此提倡限制饮酒，而非"少喝点没关系"。（来源：成人高脂血症食养指南2023）

5. **误区：只要不吃咸的菜，盐就不会超标。**
   5 g 盐的限制同时覆盖酱油、鸡精、味精、酱类、腐乳、咸菜、咸肉、酱菜等高盐调味品和加工食品；按指南交换表，约 32 g 酱油、10 g 鸡精、63 g 咸菜即相当于 5 g 盐，需一并计入。（来源：成人高脂血症食养指南2023）
