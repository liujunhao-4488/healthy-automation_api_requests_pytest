# 脑卒中饮食建议

> 本文依据国家卫生健康委《成人脑卒中食养指南（2026年版）》整理，主要面向成人脑卒中恢复期及后遗症期、生命体征稳定、意识清楚、无严重吞咽障碍或经评估后可经口进食人群的日常食养。急性期、重症、需管饲或肠外营养者应在医生或临床营养师指导下进行个体化营养治疗。

## 核心原则

指南对脑卒中人群的日常食养提出 8 条原则和建议（来源：成人脑卒中食养指南2026）：

1. **能量适宜蛋白优质，调控脂肪和碳水。** 根据身高、体重、性别、年龄、活动度、应激状况调整能量摄入；保证充足优质蛋白；控制脂肪和碳水化合物总量与质量。
2. **调钾补钙多维生素，保护神经与血管。** 维持电解质平衡，适当增加富钾食物；增加富含钙和维生素 D 的食物；通过全谷物、新鲜蔬果补充 B 族维生素、维生素 C、叶酸、DHA 等。
3. **食物多样清淡烹饪，质地软烂易吞咽。** 食物种类涵盖谷薯、蔬果、畜禽鱼蛋奶、大豆坚果和油脂；少盐少油；根据吞咽功能选择适配的食物质地。
4. **适量饮水限制饮酒，合理增稠防呛咳。** 规律少量多次饮水；吞咽障碍者对稀液体误吸风险高，必要时添加增稠剂；戒烟、尽量不饮酒。
5. **辨体辨证饮食有节，科学食养促康复。** 以"调气血、平阴阳"为核心，紧扣肝、肾、脾三脏同调，针对风、火、痰、瘀、虚辨证施膳。
6. **尽早活动全面训练，长期坚持助复健。** 病情稳定后尽早开展床上良肢位摆放、关节被动活动及运动、吞咽、语言功能训练，长期坚持。
7. **心理支持康养结合，四季养生冬为主。** 关注焦虑抑郁情绪；按四季特点调整食养；冬季加强监测、注意保暖。
8. **定期监测动态评价，自我管理防复发。** 在医生或营养专业人员指导下定期进行营养风险筛查、营养评估和血压、血脂、血糖等核心指标监测。

## 量化速查

以下数字均出自《成人脑卒中食养指南（2026年版）》原文（来源：成人脑卒中食养指南2026）。

### 一、能量与宏量营养素

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 每日能量摄入范围 | 20～35 kcal/kg 体重 |
| 卧床患者 | 约 20～25 kcal/kg/天 |
| 轻度身体活动水平者 | 约 30 kcal/kg/天 |
| 中度身体活动水平者 | 约 35 kcal/kg/天 |
| 蛋白质供能占总能量 | 15%～20% |
| 蛋白质最低量 | 至少 1.0 g/kg/天 |
| 高分解代谢状态（压疮、感染等） | 增至 1.2～1.5 g/kg/天，均匀分布于三餐 |
| 脂肪供能占总能量 | 20%～30% |
| 饱和脂肪摄入量 | 少于总能量的 10%，不超过 7% 更佳 |
| 反式脂肪酸摄入量 | 低于总能量的 1% |
| 碳水化合物供能占总能量 | 50%～65% |
| 膳食纤维每日 | 25～30 g |

### 二、各类食物每日 / 每周推荐量

| 食物类别 | 推荐量 |
| --- | --- |
| 鱼虾类 | 每周 300～500 g |
| 畜禽肉类 | 每天约 50 g |
| 鸡蛋 | 每天 1 个（合并高脂血症者注意控制胆固醇） |
| 奶类 | 每天 300～500 mL（超重肥胖者选脱脂或低脂奶） |
| 大豆（黄豆、青豆、黑豆）及其制品 | 每周 100～175 g |
| 新鲜蔬菜 | 每天 300 g 以上，深色蔬菜占一半以上 |
| 每日食物种类 | 不少于 12 种 |
| 每周食物种类 | 不少于 25 种 |

### 三、油、盐、水与饮酒

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 每日烹调用油 | 不超过 25 g |
| 每日食盐 | ＜5 g |
| 每日饮水 | 1500～1700 mL，主动、少量多次、规律饮水 |
| 饮酒 | 戒烟，尽量不饮酒 |
| 食物适宜温度 | 38～40 ℃ |
| 餐后体位 | 保持坐位或半卧位 30 分钟，防止食物反流 |

### 四、康复与监测时间节点

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 床上康复起始时间 | 发病后 24～48 小时（病情稳定后） |
| BMI 警戒值 | ＜20 kg/m² 需密切监测电解质异常 |
| 低钠盐及高钾食物不适用人群 | 高钾血症患者、终末期肾病（GFR＜30 mL/min/1.73m²）、正在使用保钾利尿剂或 ACEI 类药物且未监测血钾者 |

> 说明：指南未单独给出每日水果克数的硬性数值，仅推荐选择新鲜水果（如柚子、蓝莓、草莓、苹果、樱桃、西柚、猕猴桃、无花果等）并避免高糖水果罐头、果脯和蜜饯。

## 推荐膳食模式

指南明确提出的膳食模式如下（来源：成人脑卒中食养指南2026）：

- **参考东方健康膳食模式与得舒膳食（DASH）。** 指南原文指出，在《中国居民膳食指南（2022）》基础上，参考东方健康膳食模式或得舒膳食（Dietary Approaches to Stop Hypertension, DASH）等饮食方法，有助于改善血脂异常、促进血液循环、降低血压及保护血管，降低心脑血管疾病风险。
- **清淡少油烹饪。** 避免油炸、煎炒；推荐蒸、煮、炖、拌、汆、水溜、煨、烩等低油烹调方式，同时减少咀嚼负担。
- **优质蛋白优先。** 优先选鱼虾类、去皮禽肉、瘦畜肉、蛋类等低脂动物蛋白；奶类选脱脂或低脂奶；增加大豆蛋白。
- **全谷物与深色蔬菜为主。** 主食增加糙米、莜麦、荞麦、玉米、小米、燕麦等全谷物及杂豆、薯类；蔬菜以深色绿叶菜为主。
- **辨证施膳。** 痰热腑实证选罗汉果、火麻仁、冬瓜、白萝卜、芹菜、莴苣等清热化痰通便；痰瘀阻络证选山楂、桃仁、橘皮、紫菜、黑木耳等活血化瘀；阴虚风动证选枸杞子、黑芝麻、桑椹、银耳等补虚息风；气虚血瘀证选黄精、黄芪、山药、当归、黑木耳等健脾益气。
- **四季分养。** 春季适当食用天麻、菊花、枸杞子、决明子；初夏少量多次饮水，食用麦冬、粳米；长夏食用薏苡仁、山药、茯苓；秋季食用玉竹、乌梅、秋梨；冬季适量食用龙眼肉、干姜、肉桂、丁香等温补驱寒食药物质，但不可多食。

## 常见误区

1. **误区：脑卒中后要卧床静养、多补，不能早动手。**
   指南明确指出，病情稳定后一般在发病后 24～48 小时就可开始床上良肢位摆放、关节被动活动；尽早离床接受运动康复和认知训练可显著改善体能、平衡、步速和认知能力。长期卧床反而易致关节挛缩、肌肉萎缩、下肢静脉血栓。（来源：成人脑卒中食养指南2026）

2. **误区：吞咽困难时越稀越好，喝粥、喝汤、喝清水最安全。**
   指南指出，吞咽障碍人群对稀液体误吸风险高，饮水试验阳性者必要时应在饮品中添加增稠剂；根据吞咽功能评估结果选择对应稠度等级的食物，而不是越稀越好。进食时保持头部前倾、每次少量、速度宜慢。（来源：成人脑卒中食养指南2026）

3. **误区：得过脑卒中就一点油都不能吃，纯吃素最保险。**
   指南推荐膳食中脂肪供能比为 20%～30%，每日烹调用油不超过 25 g，而非零油；脂肪应主要来源于植物油，并适当增加深海鱼、亚麻籽、核桃等富含不饱和脂肪酸的食物。完全无油饮食会影响必需脂肪酸和脂溶性维生素摄入，不利于神经修复。（来源：成人脑卒中食养指南2026）

4. **误区：少量饮酒"活血通络"，对脑血管恢复有好处。**
   指南明确要求戒烟、尽量不饮酒；高钠、高糖、高脂肪饮食以及过量饮酒是脑卒中的重要危险因素。不存在"少量饮酒软化血管"的推荐。（来源：成人脑卒中食养指南2026）

5. **误区：脑卒中后要多吃人参、鹿茸等补品，越贵越好。**
   指南强调食养需"辨体辨证"，食药物质应在限定范围和剂量内、并咨询医生或营养指导人员后使用；不同证型（痰热、痰瘀、阴虚、气虚）选用的食药物质完全不同，误用或过量反而加重病情。日常应以均衡膳食、清淡软烂为基础，而非盲目进补。（来源：成人脑卒中食养指南2026）
