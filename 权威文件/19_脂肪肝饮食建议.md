# 脂肪肝（MASH / 代谢相关脂肪性肝病）饮食建议

> 本文依据《中国居民膳食指南（2022）》、代谢相关脂肪性肝病（MASLD/MASH）通用膳食干预原则及地中海饮食模式整理。脂肪肝患者应在消化科/肝病科医生指导下随访，饮食+运动是核心干预。

## 核心原则

1. **控制总能量，减重是第一要务。** 超重肥胖者减重 5%～10% 可显著改善脂肪肝。
2. **戒酒或严格限酒。** 酒精性和非酒精性脂肪肝都应限酒。
3. **低糖低脂，尤其限制添加糖、果糖和饱和脂肪。**
4. **高膳食纤维、全谷物、蔬果、优质蛋白。**
5. **地中海饮食模式。** 橄榄油、鱼、坚果、蔬果、全谷物。
6. **避免含糖饮料、果汁、深加工食品、油炸食品。**
7. **配合规律有氧运动和抗阻训练。**

## 量化速查

| 指标 | 推荐量 / 说明 |
| --- | --- |
| 减重目标 | 超重肥胖者 3～6 个月减 5%～10% 体重；每周减 0.5～1 kg |
| 含糖饮料/果汁 | 尽量不喝（果糖是脂肪肝重要诱因） |
| 添加糖 | 占总能量 < 10%，最好 < 5% |
| 酒精 | 尽量不饮酒；已患脂肪性肝炎者应完全戒酒 |
| 烹调油 | 每天 < 25～30 g，优先橄榄油、茶籽油、菜籽油 |
| 饱和脂肪 | 占总能量 < 10%，减少肥肉、黄油、油炸食品 |
| 膳食纤维 | 每天 25～30 g，全谷物、蔬菜、豆类 |
| 蔬菜 | 每天 300～500 g，深色占一半 |
| 水果 | 每天 200～350 g，选低 GI  whole fruit，不喝果汁 |
| 鱼类 | 每周 2～3 次，优选富脂海鱼（三文鱼、鲭鱼、沙丁鱼） |
| 坚果 | 每天 10～15 g（一小把） |
| 运动 | 每周 ≥ 150 分钟中等强度有氧运动 + 每周 2 次抗阻训练 |

## 推荐膳食模式

- **地中海饮食**：橄榄油为主要脂肪来源；多吃蔬菜、水果、全谷物、豆类、坚果；每周 2 次以上鱼；适量禽肉、蛋、奶；少量红肉；少量红酒（不推荐为健康而饮酒）。
- **减少精制碳水和果糖**：不喝含糖饮料、不喝果汁、少吃甜点；白米白面换成全谷物。
- **优质蛋白充足**：鱼、虾、去皮禽肉、豆腐、低脂奶，避免油炸。
- **黑咖啡**：适量黑咖啡（不加糖奶）与较低脂肪肝风险相关，但不建议为护肝而大量饮咖啡（来源：通用膳食共识，非指南原文）[待核实]。
- **避免超加工食品**：油炸、快餐、香肠、培根、糕点。

## 常见误区

1. **误区：脂肪肝就是"吃油太多"，吃素就好。**
   脂肪肝的核心是胰岛素抵抗和能量过剩，精制糖、果糖（含糖饮料、果汁）和精白米面同样是重要诱因；单纯吃素但大量吃白米饭、甜点、水果，脂肪肝不会改善。

2. **误区：脂肪肝没事，不用治。**
   单纯性脂肪肝可进展为脂肪性肝炎（MASH）、肝纤维化、肝硬化甚至肝癌；减重 5%～10%、改善饮食和运动是有效干预，应定期随访肝功能和肝脏超声。

3. **误区：只吃水煮菜、完全无油。**
   完全无油会导致必需脂肪酸和脂溶性维生素缺乏；应减少饱和脂肪和反式脂肪，用橄榄油、茶籽油、深海鱼、坚果等健康脂肪替代。

4. **误区：水果健康，多吃没关系，果汁也行。**
   水果本身含果糖，过量吃或喝果汁（去掉纤维、浓缩果糖）可促进肝脏脂肪合成；每天 200～350 g whole fruit 即可，不喝果汁。

5. **误区：脂肪肝是胖人的专利，瘦人不会得。**
   瘦人也可患"瘦型脂肪肝"，与代谢、饮酒、药物、遗传有关；不能因体重正常就忽视。
