# 老年营养建议

> 本文整合《成人肌少症食养指南（2026年版）》《成人骨质疏松症食养指南（2026年版）》及《中国居民膳食指南（2022）》老年人膳食要点整理。老年人常合并多种慢性病，具体方案应在医生/营养师指导下个体化调整。

## 核心原则

1. **蛋白质足量优质，三餐均衡分配。** 老年人蛋白质需求高于年轻人，以防肌肉流失。
2. **增加钙和维生素 D，保护骨骼。** 预防骨质疏松和跌倒骨折。
3. **食物细软易消化，少量多餐。** 适应咀嚼、吞咽和消化功能减退。
4. **食物多样，保证营养密度。** 每天 12 种、每周 25 种以上食物。
5. **主动足量饮水。** 老年人渴觉减退，需规律饮水。
6. **适度运动，抗阻+平衡训练。** 延缓肌少症和骨质疏松。
7. **定期筛查营养不良、肌少症和骨质疏松风险。**

## 量化速查

### 一、蛋白质（来源：成人肌少症食养指南2026）

| 指标 | 推荐量 |
| --- | --- |
| 65 岁以上老年人蛋白质推荐 | 1.17 g/kg 体重/天 |
| 肌少症（肾功能正常） | 1.2～1.5 g/kg 体重/天 |
| 优质蛋白占总蛋白比例 | 尽可能 ≥ 60% |
| 每餐蛋白质目标 | 20～25 g，最大化肌肉蛋白合成 |
| 鱼虾类 | 每周 300～500 g |
| 畜禽瘦肉 | 每周 300～500 g |
| 鸡蛋 | 每天 1 个 |
| 奶 | 每天 300～500 mL |
| 大豆 | 每周约 105 g |

### 二、钙与维生素 D（来源：成人骨质疏松症食养指南2026）

| 指标 | 推荐量 |
| --- | --- |
| 钙（50 岁以上中老年人） | 每天 1000～1200 mg；可耐受最高 2000 mg |
| 维生素 D（18～64 岁） | 每天 10 μg（400 IU） |
| 维生素 D（65 岁以上） | 每天 15 μg（600 IU） |
| 血清 25(OH)D 目标 | ≥ 30 ng/mL（≥ 75 nmol/L），不超过 150 ng/mL |
| 奶制品 | 每天 300 mL 以上液态奶或相当量 |
| 日晒 | 上午 10 点前/下午 2 点后，裸露面部、手部、手臂 10～20 分钟 |

### 三、蔬果与食物多样（来源：成人骨质疏松症食养指南2026）

| 指标 | 推荐量 |
| --- | --- |
| 蔬菜 | 65 岁以上每天 300～450 g，深色占一半以上 |
| 水果 | 65 岁以上每天 200～300 g |
| 全谷物 | 不低于每天主食量 30% |
| 坚果 | 每周 50～70 g |
| 每天食物种类 | ≥ 12 种 |
| 每周食物种类 | ≥ 25 种 |

### 四、饮水与生活方式

| 指标 | 推荐量 |
| --- | --- |
| 每日饮水 | 1500～1700 mL，少量多次，首选白开水（来源：成人脑卒中食养指南2026） |
| 食盐 | 每天 < 5 g（来源：成人高血压食养指南） |
| 烹调油 | 每天 < 25～30 g |

## 推荐膳食模式

- **高蛋白三餐均衡**：每餐都有优质蛋白（蛋、奶、鱼、瘦肉、大豆），而非集中在晚餐。
- **奶+豆制品+深绿菜补钙**：每天 300 mL 以上奶，常吃豆腐、深绿色叶菜；菠菜、苋菜等草酸高的菜先焯水。
- **细软易消化**：食物切小煮软，必要时用匀浆、增稠、酶解；发酵食品（酸奶、纳豆、发面馒头）更易消化。
- **配合抗阻+平衡运动**：弹力带、沙袋绑腿、哑铃每周 2～3 次；太极拳、八段锦改善平衡、降低跌倒风险。
- **素食老人特别注意**：易缺优质蛋白、维生素 D、B12、铁、锌、n-3 脂肪酸，应增加蛋奶、菌菇、大豆及发酵豆制品。

## 常见误区

1. **误区：老年人吃得越少越健康，清淡就是只喝粥吃咸菜。**
   老年人蛋白质需求高于年轻人（1.2～1.5 g/kg/天），长期喝粥吃素会加速肌肉流失（肌少症）和骨质疏松。（来源：成人肌少症食养指南2026）

2. **误区：骨头汤能补钙。**
   骨头汤钙含量极低，主要是脂肪和嘌呤；补钙首选奶及奶制品，每天 300 mL 以上。（来源：成人骨质疏松症食养指南2026）

3. **误区：老年人要少动，免得摔倒骨折。**
   适度抗阻和平衡运动反而延缓骨丢失、增强肌肉、降低跌倒风险；完全不动会加速肌少症和骨质疏松。（来源：成人肌少症食养指南2026、成人骨质疏松症食养指南2026）

4. **误区：不渴就不用喝水。**
   老年人口渴觉减退，应主动、少量多次饮水，每天 1500～1700 mL；脱水可加重便秘、血栓、意识模糊。（来源：成人脑卒中食养指南2026）

5. **误区：补钙越多越好。**
   钙可耐受最高摄入量为每天 2000 mg，过量增加肾结石和心血管风险；优先膳食摄入，不足时在医生指导下补充。（来源：成人骨质疏松症食养指南2026）
