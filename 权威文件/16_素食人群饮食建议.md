# 素食人群饮食建议

> 本文依据《中国居民膳食指南（2022）》素食人群膳食指南及《成人肌少症食养指南（2026年版）》素食相关提示整理。素食（全素/蛋素/奶素/蛋奶素）易出现蛋白质、维生素 B12、铁、锌、n-3 脂肪酸、维生素 D 缺乏，需主动搭配补充。

## 核心原则

1. **谷类为主，食物多样。** 每天 12 种、每周 25 种以上食物，合理搭配。
2. **增加全谷物、杂豆、大豆及其制品。** 大豆是素食者最重要的优质蛋白来源。
3. **常吃坚果、菌菇和海藻。** 补充 n-3 脂肪酸、锌、硒、碘等。
4. **合理搭配，提高营养素利用率。** 利用维生素 C 促进铁吸收，避免咖啡浓茶与餐同食。
5. **规律使用强化食品或营养补充剂。** 尤其维生素 B12。
6. **增加户外活动，适量晒太阳。** 预防维生素 D 缺乏。
7. **老年人素食者更应关注蛋白质摄入**，预防肌少症。

## 量化速查

以下数字综合《中国居民膳食指南（2022）》素食人群建议及 DRIs（来源：中国居民膳食指南2022）。

### 一、关键营养素与食物

| 营养素 / 食物 | 推荐策略 |
| --- | --- |
| 大豆及其制品 | 每天 50 g 大豆当量（北豆腐约 150 g、豆浆约 650 mL）；全素者可适当增加 |
| 全谷物 | 占全天主食 1/3 以上，与杂豆搭配 |
| 坚果 | 每天 20～30 g |
| 菌菇类 | 每周多次，富含维生素 B2、铁、锌、硒 |
| 海藻（海带、紫菜等） | 每周 1～2 次，补碘 |
| 维生素 B12 | 素食者最易缺乏，应通过强化食品或补充剂获取，定期监测 |
| n-3 脂肪酸 | 亚麻籽、奇亚籽、核桃、紫苏油、亚麻籽油；必要时藻油 DHA/EPA |
| 铁 | 首选富含维生素 C 的餐食搭配植物性铁（黑木耳、芝麻、红豆、菠菜）；必要时在医生指导下补充铁剂 |
| 锌 | 豆类、全谷物、坚果、小麦胚芽 |
| 钙 | 豆腐（卤水/石膏点）、深绿色叶菜、芝麻酱、强化植物奶 |
| 维生素 D | 户外活动晒太阳 + 必要时补充剂 |

### 二、不同素食类型注意点

| 类型 | 特别提示 |
| --- | --- |
| 全素（纯素） | 最需关注维生素 B12、n-3、铁、锌、钙、维生素 D；建议使用强化食品或补充剂 |
| 蛋素 | 每天 1 个鸡蛋可提供优质蛋白、维生素 B12、胆碱 |
| 奶素 | 每天 300～500 mL 奶可提供钙、优质蛋白、维生素 B12 |
| 蛋奶素 | 营养相对均衡，仍需注意铁、锌、n-3 |

## 推荐膳食模式

- **主食：全谷物 + 杂豆搭配**（如红豆饭、绿豆粥、燕麦、藜麦），提高蛋白质互补和铁锌摄入。
- **每餐都有大豆制品**：豆腐、豆干、豆浆、天贝、纳豆（发酵豆制品更易消化且含维生素 B12 前体）。
- **餐餐有蔬菜、深色占一半**，尤其深绿色叶菜补叶酸、钙、铁。
- **维生素 C 与植物铁同食**：彩椒、番茄、柑橘与豆类、全谷物同餐。
- **避免咖啡、浓茶与正餐同时**：鞣酸抑制铁吸收，应在两餐间饮用。
- **烹饪用植物油**：亚麻籽油、紫苏油、菜籽油、核桃油等富 n-3。

## 常见误区

1. **误区：吃素就一定健康、不会得慢性病。**
   长期纯素易导致优质蛋白、维生素 B12、铁、锌、n-3、钙缺乏，老年人易患肌少症、贫血、骨质疏松；指南明确指出素食人群更容易患肌少症。（来源：成人肌少症食养指南2026）

2. **误区：吃菠菜、红枣就能补铁。**
   植物性铁（非血红素铁）吸收率仅约 5%～10%，远低于动物性铁（20%～30%）；素食者需靠维生素 C 促进吸收，并定期监测血红蛋白和铁蛋白。

3. **误区：喝骨头汤/吃芝麻酱就能补钙。**
   芝麻酱热量高、骨头汤钙极低；素食者补钙应靠卤水/石膏豆腐、深绿色叶菜、强化植物奶，并配合晒太阳。

4. **误区：素食不会缺维生素 B12，植物里都有。**
   维生素 B12 几乎只存在于动物性食物中，发酵豆制品含量不稳定；纯素者必须通过强化食品或补充剂获取，否则可致巨幼细胞贫血和神经损伤。（来源：中国居民膳食指南2022）

5. **误区：橄榄油/茶籽油是素食就随便用。**
   素食者应优先选择富含 α-亚麻酸的油（亚麻籽油、紫苏油、核桃油），并常吃核桃、奇亚籽，以弥补缺乏海鱼带来的 n-3 不足。（来源：中国居民膳食指南2022）
