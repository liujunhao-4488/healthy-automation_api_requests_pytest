# 便秘饮食建议

> 本文依据《中国居民膳食指南（2022）》、《中国慢性便秘诊治指南》通用膳食建议整理。便秘原因复杂，若持续不缓解、伴便血/体重下降/腹痛，应及时就医排查器质性病因。

## 核心原则

1. **足量膳食纤维。** 多吃全谷物、蔬菜、水果、豆类。
2. **主动足量饮水。** 膳食纤维需要足够水分才能发挥作用。
3. **适量脂肪和天然轻泻食物。** 如芝麻、核桃、西梅、火龙果。
4. **建立规律排便习惯。** 晨起或餐后如厕，适度活动。
5. **减少精细加工、辛辣刺激和低渣饮食。**
6. **适度运动，避免久坐。**

## 量化速查

| 指标 | 推荐量 / 说明 |
| --- | --- |
| 膳食纤维 | 每天 25～30 g（成人推荐 25～30 g；从低剂量逐步增加，避免突然大量） |
| 饮水 | 每天 1500～2000 mL（约 1.5～2 L），晨起空腹一杯温水 |
| 蔬菜 | 每天 300～500 g，深色占一半以上 |
| 水果 | 每天 200～350 g；优选西梅、火龙果、猕猴桃、苹果（带皮）、梨 |
| 全谷物 | 占主食 1/3 以上（燕麦、糙米、全麦、玉米、红薯） |
| 豆类 | 每周多次（红豆、黑豆、芸豆、鹰嘴豆） |
| 坚果/种子 | 每天一小把（芝麻、杏仁、亚麻籽） |
| 活动 | 每天步行 30 分钟以上，腹部按摩 |

> 说明：以上数字综合《中国居民膳食指南（2022）》及慢性便秘通用管理建议；不同指南对膳食纤维具体数值略有差异，新增加纤维者应从 10～15 g/天起步逐步加量，避免胀气。

## 推荐膳食模式

- **高纤早餐**：燕麦粥 + 奇异果/西梅 + 坚果。
- **主食"粗细搭配"**：白米中掺糙米、燕麦、红豆、玉米。
- **每天有带皮水果**：苹果、梨带皮吃；西梅（干）、火龙果（尤其红心）、猕猴桃是公认的通便水果（含山梨糖醇、膳食纤维）。
- **充足水分**：晨起空腹 300 mL 温水，白天少量多次。
- **适量油脂**：芝麻、核桃、橄榄油、牛油果，脂肪能润滑肠道。
- **发酵食品**：酸奶、泡菜、纳豆等含益生菌，有助于肠道蠕动。
- **避免长期依赖**：浓茶、咖啡、辣椒、精加工低渣食物、长期卧床。

## 常见误区

1. **误区：便秘就吃香蕉，越生越好。**
   未成熟香蕉含大量鞣酸，反而加重便秘；通便应选熟透的香蕉、西梅、火龙果、猕猴桃等含山梨糖醇的水果。

2. **误区：只吃菜不喝水，纤维越多越通便。**
   膳食纤维需要足够水分才能在肠道内膨胀、软化粪便；喝水不足时，高纤维反而可能加重腹胀甚至梗阻。

3. **误区：便秘就喝番泻叶、肠清茶、酵素。**
   长期使用刺激性泻药可致结肠黑变、依赖和电解质紊乱；应优先靠饮食、运动和习惯调整，必要时在医生指导下使用渗透性缓泻剂（如乳果糖、聚乙二醇）。

4. **误区：喝粥吃流食最养胃通便。**
   白粥、白面条等低渣食物几乎不含纤维，反而使粪便体积不足、加重便秘；应增加全谷物和蔬菜。

5. **误区：老年人便秘是正常的，不用管。**
   老年人便秘可能是脑卒中、帕金森、药物副作用、肠道肿瘤的信号；若伴随便血、黑便、体重下降、贫血或排便习惯突然改变，必须就医。
