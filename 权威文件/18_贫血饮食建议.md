# 缺铁性贫血饮食建议

> 本文依据《中国居民膳食指南（2022）》及缺铁性贫血膳食干预通用建议整理。贫血原因众多（缺铁、缺叶酸/B12、慢性病失血等），确诊和治疗应在医生指导下进行，食物不能替代铁剂治疗。

## 核心原则

1. **优先补充血红素铁。** 动物血、肝脏、红肉吸收率高。
2. **维生素 C 促进植物铁吸收。** 餐食搭配蔬果。
3. **抑制铁吸收的食物与餐食错开。** 咖啡、浓茶、高钙食品、植酸高的食物避免与含铁餐同食。
4. **同时补充叶酸和维生素 B12。** 预防巨幼细胞性贫血。
5. **查找并纠正失血原因。** 如月经过多、消化道出血、痔疮。
6. **定期复查血红蛋白和铁蛋白。**

## 量化速查

| 指标 | 推荐量 / 说明 |
| --- | --- |
| 血红素铁食物（优先） | 动物血（猪血、鸭血）、动物肝（猪肝、鸡肝）、瘦红肉（牛、羊、猪瘦肉） |
| 植物性铁食物 | 黑木耳、芝麻酱、红豆、菠菜、豆腐干、燕麦（吸收率约 5%～10%） |
| 维生素 C 食物 | 彩椒、西兰花、番茄、橙子、猕猴桃、鲜枣，与含铁餐同食 |
| 动物肝脏 | 每周 1～2 次，每次约 20～50 g（孕妇注意维生素 A 不过量） |
| 动物血 | 每周 1～2 次，每次 50～100 g |
| 红肉 | 每天 40～75 g（畜禽肉总量参考膳食指南） |
| 咖啡、浓茶 | 避免与正餐同服，最好在两餐之间（餐后 1 小时以上） |
| 钙补充剂/奶 | 与铁剂和高铁餐错开 2 小时以上 |
| 叶酸 | 深绿色叶菜、豆类、动物肝；孕期需额外补充 400 μg |
| 维生素 B12 | 动物性食物（肉、蛋、奶、肝）；纯素者必须补充 |

## 推荐膳食模式

- **高铁 + 高维C 同餐**：青椒炒猪肝、番茄炖牛肉、彩椒炒瘦肉、橙子/猕猴桃作为餐后水果。
- **每周 1～2 次动物血或肝**：猪血豆腐汤、爆炒猪肝、鸭血粉丝。
- **红肉每天都有**：瘦牛肉、猪里脊。
- **植物铁搭配**：黑木耳炒肉、红豆饭、芝麻酱拌面。
- **避免同服**：餐时不喝咖啡、浓茶；钙片、牛奶、抗酸药与铁剂错开 2 小时。
- **使用铁制炊具**：铁锅炒菜可增加少量铁摄入。

## 常见误区

1. **误区：红枣、红糖、菠菜能补血。**
   红枣、红糖铁含量低且为非血红素铁，吸收率仅约 3%～5%；菠菜铁吸收率也很低且含草酸。真正高效的是动物血、肝、红肉。

2. **误区：贫血就多喝牛奶、多吃钙片。**
   钙会抑制铁吸收；牛奶、钙片应与高铁餐和铁剂错开 2 小时以上。

3. **误区：饭后喝浓茶/咖啡助消化。**
   浓茶中的鞣酸、咖啡中的多酚会与铁结合成难溶物，显著抑制铁吸收；应在两餐之间饮用。

4. **误区：只要食补就行，不用吃铁剂。**
   已经确诊缺铁性贫血者，单靠食物通常无法快速纠正血红蛋白，需在医生指导下口服铁剂（如硫酸亚铁、富马酸亚铁），饮食作为辅助；否则贫血会持续损害健康。

5. **误区：贫血就是缺铁，补铁就行。**
   贫血还可能由缺乏叶酸/维生素 B12（巨幼细胞性贫血）、慢性疾病、地中海贫血、消化道出血等引起；应先查铁蛋白、血常规、必要时查叶酸、B12，对因治疗。
