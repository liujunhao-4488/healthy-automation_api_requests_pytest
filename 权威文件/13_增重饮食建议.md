# 健康增重饮食建议

> 本文参考 Mayo Clinic 健康增重指南思路及《中国居民膳食营养素参考摄入量（2023版）》《中国居民膳食指南（2022）》整理，面向体重过轻、需要健康增肌而非单纯增脂的人群。增重应配合力量训练并在医生/营养师指导下进行。

## 核心原则

1. **热量盈余但不过量。** 在维持当前体重的能量基础上逐步增加摄入，优先保证肌肉合成而非脂肪堆积。
2. **蛋白质充足且每餐分布。** 保证优质蛋白摄入，三餐均匀分配，配合力量训练促进肌肉增长。
3. **提高营养密度而非空热量。** 选择坚果、牛油果、全脂奶、豆类等高密度食物，避免高糖高油垃圾食品。
4. **少食多餐。** 胃口小者通过增加餐次弥补单次进食量不足。
5. **力量训练是关键。** 没有抗阻训练，多余热量主要转化为脂肪而非肌肉。
6. **规律监测。** 每周称重，按 0.25～0.5 kg/周的节奏调整，避免体重过快增长。

| 指标 | 推荐量 / 说明 |
| --- | --- |

| 每周增重目标 | 0.25～0.5 kg（健康节奏） |
| 蛋白质摄入 | 有抗阻训练者建议 1.2～1.6 g/kg 体重/天（参考中国居民膳食营养素参考摄入量及运动人群推荐）[待核实] |
| 每餐蛋白质目标 | 20～30 g 优质蛋白，均匀分布于三餐（来源：成人肌少症食养指南2026 及运动营养共识） |
| 餐次安排 | 3 正餐 + 1～2 次加餐，避免一次吃太多 |
| 坚果 | 每天一小把（约 15～30 g） |
| 奶及奶制品 | 全脂奶每天 300～500 mL 或相当量酸奶、奶酪 |
| 力量训练 | 每周 2～3 次抗阻训练，重点练大肌群 |

## 推荐膳食模式

- **热量盈余+高蛋白+抗阻训练** 三者结合。
- **高密度加餐**：全脂奶+坚果、酸奶+水果+燕麦、花生酱面包、鸡蛋+牛奶等，而非薯片、甜饮料。
- **主食不省**：在现有饭量基础上增加全谷物、薯类、米面。
- **避免餐前大量喝水**，以免占用胃容量影响正餐进食。

## 常见误区

1. **误区：增重就是顿顿炸鸡、奶茶、甜点。**
   空热量食物会主要增加脂肪而非肌肉，且带来血脂、血糖问题；应通过坚果、全脂奶、牛油果、豆类、优质蛋白等高密度食物制造热量盈余。

2. **误区：吃得多就行，不用运动。**
   没有抗阻训练，多余热量主要变为脂肪；只有配合力量训练，额外蛋白质和热量才能有效转化为肌肉。

3. **误区：一顿吃越多越好。**
   胃口小者强行暴食易导致胃肠不适；应少食多餐，把额外热量分散到加餐中。

4. **误区：吃素/喝粥就能长胖。**
   白粥、素菜热量密度低，长期吃反而难以增重；需要增加优质蛋白和健康脂肪。

5. **误区：体重涨得越快越好。**
   每周 0.25～0.5 kg 是健康节奏；过快增重多为脂肪和水分，应每周称重并动态调整。
