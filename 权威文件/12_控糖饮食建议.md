# 日常控糖 / 血糖管理饮食建议

> 本文依据国家卫生健康委《成人糖尿病食养指南（2023年版）》及《中国居民膳食指南（2022）》整理，面向糖尿病前期、血糖偏高及 2 型糖尿病人群日常膳食参考。具体用药与能量方案应在医师或营养指导人员指导下制定。

## 核心原则

指南对糖尿病患者日常食养提出 8 条原则（来源：成人糖尿病食养指南2023）：

1. **食物多样，养成和建立合理膳食习惯。** 五大类食物（谷薯、蔬菜水果、动物性食物、大豆坚果、烹调油盐）搭配，少油少盐少糖。
2. **能量适宜，控制超重肥胖和预防消瘦。** 维持 BMI 在 18.5～23.9 kg/m²；超重肥胖者逐步减重，消瘦者增加能量和蛋白质。
3. **主食定量，优选全谷物和低升糖指数（GI）食物。** 全谷物、杂豆类应占主食 1/3 以上。
4. **积极运动，改善体质和胰岛素敏感性。** 餐后规律运动，结合抗阻训练。
5. **清淡饮食，限制饮酒，预防和延缓并发症。** 控制油、盐、糖，不饮酒。
6. **食养有道，合理选择应用食药物质。** 按中医辨证（阴虚热盛、气阴两虚、阴阳两虚）选食。
7. **规律进餐，合理加餐，促进餐后血糖稳定。** 定时定量，细嚼慢咽，先吃菜后吃主食。
8. **自我管理，定期营养咨询，提高血糖控制能力。** 记录膳食、运动和血糖。

## 量化速查

以下数字出自《成人糖尿病食养指南（2023年版）》（来源：成人糖尿病食养指南2023）。

### 一、能量与宏量营养素

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 健康体重 BMI | 18.5～23.9 kg/m² |
| 宏量营养素供能比 | 蛋白质 15%～20%、碳水化合物 45%～60%、脂肪 20%～35% |
| 以成年人 1800～2000 kcal 计，每日碳水化合物总量 | 200～300 g |
| 60 kg 轻体力活动成年女性每日能量参考 | 1500～1800 kcal |
| 超重肥胖 2 型糖尿病患者减重幅度 | 3%～5% 即有临床意义；3～6 个月减 5%～10% |
| 减重速度 | 每月 1～2 kg |

### 二、食物推荐量

| 食物类别 | 推荐量 |
| --- | --- |
| 蔬菜 | 每天 500 g，深色蔬菜占一半以上 |
| 全谷物和杂豆占主食比例 | 1/3 以上 |
| 烹调油 | 每天 < 25 g |
| 食盐 | 每天 < 5 g |
| 饮水 | 足量白开水，不喝含糖饮料；可适量淡茶或咖啡 |

### 三、运动

| 指标 | 推荐量 |
| --- | --- |
| 有氧运动频率 | 每周至少 5 天，每次 30～45 分钟 |
| 中等强度运动占比 | 50% 以上（快走、骑车、乒乓、羽毛球、慢跑、游泳等） |
| 抗阻运动 | 每周最好 2 次（哑铃、俯卧撑、器械等） |

## 推荐膳食模式

- **低 GI 平衡膳食。** 选择低 GI 主食（全谷物、杂豆、蔬菜），蛋白质充足，脂肪适量且以植物油为主。
- **进餐顺序：先吃菜、再吃肉、最后吃主食。** 指南明确指出调整进餐顺序对控制血糖有利。
- **定时定量、少食多餐。** 病程长、血糖波动大或用胰岛素者可在两餐间合理加餐预防低血糖。
- **清淡少油盐糖。** 避免含糖饮料、甜点、加工肉类、烟熏烘烤腌制食品。

## 常见误区

1. **误区：糖尿病就是不能吃主食，碳水越低越好。**
   指南推荐碳水化合物仍占总能量 45%～60%（约每天 200～300 g），并非零碳水；关键是定量、选低 GI、全谷物占 1/3 以上。过度低碳水反而可能导致酮症、肌肉流失和血糖波动。（来源：成人糖尿病食养指南2023）

2. **误区：无糖食品可以随便吃。**
   无糖食品本身仍含淀粉、脂肪，碳水化合物总量需计入全天；不喝含糖饮料不等于无限制吃无糖糕点。（来源：成人糖尿病食养指南2023）

3. **误区：只要不吃甜的，血糖就不会高。**
   白米饭、白面条、白馒头等精制谷物升糖速度不亚于糖；指南要求全谷物、杂豆占主食 1/3 以上，并先吃菜后吃主食以平稳餐后血糖。（来源：成人糖尿病食养指南2023）

4. **误区：喝酒不影响血糖，少量红酒还能"活血"。**
   指南明确要求不饮酒；酒精可导致血糖波动，使用胰岛素或促泌剂者还可能诱发低血糖，且常伴随总能量超标。（来源：成人糖尿病食养指南2023）

5. **误区：水果甜就完全不能吃。**
   指南要求水果限量但不必完全禁食；应选择低 GI 水果、计入全天碳水总量，并在两餐之间食用，避免果汁和水果制品。（来源：成人糖尿病食养指南2023）
