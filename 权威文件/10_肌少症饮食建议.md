# 肌少症饮食建议

> 本文依据国家卫生健康委《成人肌少症食养指南（2026年版）》整理。肌少症（肌肉衰减综合征）是一种与年龄相关、受不良生活方式和疾病影响的进行性骨骼肌量减少、肌肉力量下降和/或肌肉功能减退的综合征。指南主要面向成人肌少症人群日常食养及基层营养指导人员参考。

## 核心原则

指南对肌少症人群的日常食养提出 7 条原则和建议（来源：成人肌少症食养指南2026）：

1. **蛋白优质足量，三餐均衡分配。** 增加蛋白质摄入以保证肌肉蛋白质合成；优质蛋白比例尽可能达到 60% 以上；三餐均衡分配蛋白质，每餐达到一定量以最大化促进肌肉蛋白合成。
2. **增加营养密度，膳食细软好吸收。** 优先选择高营养密度食物（高蛋白食物、全谷物、深色蔬果、坚果、动物肝脏等），避免精制糖、酒精和超加工食品；对咀嚼吞咽困难者通过匀浆、增稠、酶解等方式降低咀嚼难度。
3. **按需补充营养，精准增加肌肉。** 日常膳食无法满足能量和蛋白质需求时及时进行口服营养补充（ONS）；可精准补充亮氨酸、β-羟基-β-甲基丁酸钙（CaHMB）、维生素 D 等靶向营养素。
4. **主动多元运动，加强抗阻锻炼。** 减少静坐/卧床时间，以抗阻运动为核心，结合有氧运动、平衡训练和柔韧性训练。
5. **调理脾胃为本，科学选用食药物质。** 以补益气血、健脾生肌为核心，按脾胃虚弱证、肝肾不足证、脾胃湿热证辨证施膳。
6. **管控基础疾病，合理调整食养方案。** 合并肥胖、糖尿病、慢性肾病、肿瘤等基础疾病者，在规范治疗同时给予个性化食养。
7. **监测肌少风险，早筛早诊早干预。** 肌肉量 30 岁左右达峰，之后随年龄流失加速；提倡关口前移，定期筛查握力、小腿围、步速、5 次起坐时间等。

## 量化速查

以下数字均出自《成人肌少症食养指南（2026年版）》原文（来源：成人肌少症食养指南2026）。

### 一、蛋白质与能量

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 65 岁及以上老年人蛋白质推荐摄入量 | 每天每公斤体重 1.17 g |
| 肾功能正常的肌少症人群蛋白质 | 每天每公斤体重 1.2～1.5 g |
| 优质蛋白占总蛋白质比例 | 尽可能达到 60% 以上 |
| 每餐蛋白质摄入目标 | 20～25 g（以最大化促进肌肉蛋白合成） |
| 每日能量摄入目标 | 每天每公斤体重 25～30 kcal |
| 膳食能量或蛋白质不足时的干预 | 及时进行口服营养补充（ONS） |

### 二、各类食物推荐量

| 食物类别 | 推荐量 |
| --- | --- |
| 鱼虾类（水产品） | 每周 300～500 g，或每周 2 次 |
| 畜禽瘦肉（畜肉、禽肉） | 每周 300～500 g |
| 鸡蛋 | 每天 1 个（或每周 300～500 g 蛋类） |
| 奶及奶制品 | 每天 300～500 mL 液态奶或相当量乳制品 |
| 大豆及制品 | 每周约 105 g 大豆或相当量豆制品 |

### 三、口服营养补充与靶向营养素

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 乳清蛋白（膳食蛋白质不足者） | 每天 20～40 g；全素食者可补充大豆蛋白 |
| 亮氨酸（老年人补充） | 每天 1.2～6.0 g |
| β-羟基-β-甲基丁酸钙（CaHMB） | 每天 ≤ 6.0 g |
| 血清 25-羟基维生素 D [25(OH)D] 目标水平 | ≥ 75 nmol/L（≥ 30 ng/mL） |
| 血清 25(OH)D 上限 | 不超过 150 nmol/L（60 ng/mL），避免血钙升高 |
| 乳清蛋白粉冲调水温 | 40 ℃ 以下温水溶解 |

### 四、运动处方

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 抗阻运动 | 每周 2～3 次，每次 30～60 分钟；可使用弹力带、沙袋绑腿或哑铃 |
| 有氧运动 | 每周至少 3 次，每次 30 分钟以上（步行、踏步、骑健身车、健身舞、五禽戏等） |
| 运动时心率 | 极限心率（约 220 － 年龄）的 50%～80% |
| 静态平衡训练 | 从每次坚持 10 秒开始，逐渐增加至 1～2 分钟 |
| 动态平衡训练 | 每次 10 分钟（起坐、行走、交叉踱步、八段锦、太极拳等） |
| 柔韧性训练 | 每月累计至少 2 周，每次 10 分钟（颈部、肩部、膝盖等关节） |

### 五、筛查与监测

| 指标 | 推荐量 / 限值 |
| --- | --- |
| 肌肉量达峰年龄 | 30 岁左右 |
| 普通老年人肌少症筛查频率 | 每年 1 次 |
| 高风险人群（高龄、低 BMI、少活动、营养不良、绝经期女性、合并慢性病）及已确诊患者 | 每 3 个月至半年 1 次 |
| 60 岁及以上老年人肌少症患病率 | 5.7%～23.9%（随年龄增长显著增加） |
| 急性与慢性肌少症时间切点 | 6 个月 |

## 推荐膳食模式

指南提出的膳食原则如下（来源：成人肌少症食养指南2026）：

- **高营养密度、高蛋白膳食。** 在同等能量下优先选择高营养密度食材：高蛋白食物以鱼虾、禽畜瘦肉、蛋、奶等动物性食品和大豆制品为主；高维生素矿物质食物包括全谷物、深色蔬菜水果、坚果、动物肝脏；避免精制糖、酒精和超加工食品。
- **三餐均衡分配蛋白质。** 不要集中在一餐吃肉蛋奶，而是每餐都有 20～25 g 优质蛋白，以最大化肌肉蛋白合成。
- **细软易消化膳食。** 老年肌少症常伴咀嚼吞咽困难、消化吸收功能减退，可通过匀浆、增稠、酶解处理肉类和蔬菜；发面馒头、酸奶、纳豆等发酵食品更易消化；可向牛奶中添加全营养配方粉或乳清蛋白提高营养密度。
- **素食者特别注意。** 素食人群容易缺乏优质蛋白、维生素 D、n-3 脂肪酸、维生素 B12，更容易患肌少症，应多摄入蛋类、奶及奶制品、菌菇类、大豆及豆制品，并尽可能多选发酵豆制品。
- **合并症个体化膳食。** 合并肥胖者选低脂高蛋白高膳食纤维膳食；合并糖尿病者选低血糖生成指数主食并保证足量蛋白质；合并慢性肾病者按肾功能计算能量和蛋白质，以优质蛋白为主；合并肿瘤者摄入充足能量、蛋白质及抗炎抗氧化食物。
- **中医辨证施膳。** 脾胃虚弱证选山药、大枣、龙眼肉、茯苓、黄芪、党参等健脾益气类；肝肾不足证选山茱萸、肉苁蓉、阿胶、枸杞、桑椹等补益肝肾类；脾胃湿热证选白扁豆、赤小豆、薏苡仁等清利湿热类。

> 说明：本指南原文未直接使用"DASH 饮食""东方健康膳食模式"等命名，核心推荐为"高营养密度、高蛋白、三餐均衡、细软易消化"的膳食模式。

## 常见误区

1. **误区：肌少症就是"人老了正常"，吃不动、走不动没办法，只能静养。**
   指南明确指出肌少症是一种独立疾病（已纳入 ICD 编码），且肌肉量 30 岁达峰后即开始流失，应关口前移、早筛早诊早干预；抗阻运动是延缓肌少症的重要手段，长期静养反而加速肌肉流失。（来源：成人肌少症食养指南2026）

2. **误区：老年人吃素更健康，少吃肉、多喝粥就能养生。**
   指南明确指出素食人群容易缺乏优质蛋白、维生素 D、n-3 脂肪酸、维生素 B12，更容易患肌少症；肌少症人群反而需要每天 1.2～1.5 g/kg 蛋白质、优质蛋白占比 60% 以上，长期喝粥吃素会加重肌肉流失。（来源：成人肌少症食养指南2026）

3. **误区：只要吃蛋白粉、钙片、维生素片就够了，不用好好吃饭。**
   指南强调肌少症防治应以全面均衡膳食为基础，口服营养补充（ONS）和靶向营养素（乳清蛋白、亮氨酸、CaHMB、维生素 D）只是在日常膳食无法满足需求时的补充；不能替代天然食物，也不能替代运动。（来源：成人肌少症食养指南2026）

4. **误区：补蛋白越多越好，一顿把一天的肉蛋奶吃完就行。**
   指南指出每餐 20～25 g 蛋白质摄入即可最大化促进肌肉蛋白合成，超过该量的蛋白质可能被氧化或转化为尿素、有机酸排出；三餐均衡分配比集中一餐大吃大喝更有利于四肢骨骼肌量增长。（来源：成人肌少症食养指南2026）

5. **误区：老年人运动容易骨折、闪腰，少动为宜。**
   指南要求以抗阻运动为核心（每周 2～3 次），结合有氧运动、平衡训练和柔韧性训练；平衡训练可降低跌倒风险，柔韧性训练改善关节活动度。当然运动前应由专业人员做健康状况和运动风险评估，循序渐进。（来源：成人肌少症食养指南2026）
