# 孕期 / 哺乳期营养建议

> 本文依据《中国居民膳食指南（2022）》孕妇乳母篇及《中国居民膳食营养素参考摄入量（2023版）》整理。孕期营养方案应在产科医生或营养师指导下个体化执行。

## 核心原则

1. **补充叶酸，常吃含铁食物，选用碘盐。** 备孕期即开始补叶酸。
2. **孕吐严重者，可少量多餐，保证摄入含必要量碳水化合物的食物。**
3. **孕中晚期适量增加奶、鱼、禽、蛋、瘦肉的摄入。**
4. **适量身体活动，维持孕期适宜增重。**
5. **禁烟酒，愉快孕育新生命，积极准备母乳喂养。**
6. **哺乳期食物多样，不过量；增加富含优质蛋白及维生素 A 的动物性食物和海产品。**

## 量化速查

以下数字出自《中国居民膳食指南（2022）》孕妇乳母篇及 DRIs（来源：中国居民膳食指南2022）。

### 一、关键微量营养素

| 营养素 | 推荐量 |
| --- | --- |
| 叶酸 | 孕前 3 个月开始每天补充 400 μg DFE；孕期继续每天 400 μg；哺乳期每天 550 μg |
| 碘 | 孕期及哺乳期需增加碘摄入，食用加碘盐；每周摄入 1～2 次富碘食物（如海带、紫菜） |
| 铁 | 孕期需增加铁摄入；中晚期常需在医生指导下补充铁剂 |
| 钙 | 孕早期每天 800 mg；孕中晚期及哺乳期每天 1000 mg |
| DHA | 孕 20 周后适量增加，推荐每周吃 2～3 次鱼，至少 1 次富脂海鱼 |

### 二、各类食物增量

| 食物 | 推荐量 |
| --- | --- |
| 奶及奶制品 | 每天 300～500 mL（或相当量酸奶、奶酪），约可提供一半钙需求 |
| 动物性食物（鱼、禽、蛋、瘦肉） | 孕中晚期在非孕期基础上每天增加约 50 g，孕晚期再增加 50 g |
| 鸡蛋 | 每天 1 个 |
| 每周鱼类 | 2～3 次，至少 1 次富脂海鱼（如三文鱼、鳕鱼、带鱼） |
| 含铁食物 | 动物血、肝脏、红肉（瘦肉），同时配维生素 C 促进吸收 |

### 三、孕期体重增长参考

| 孕前 BMI | 孕期总增重范围 |
| --- | --- |
| 低体重（< 18.5） | 12.5～18 kg |
| 正常体重（18.5～23.9） | 11.5～16 kg |
| 超重（24～27.9） | 7～11.5 kg |
| 肥胖（≥ 28） | 5～9 kg |

## 推荐膳食模式

- **食物多样、搭配合理**，在平衡膳食基础上关键营养素增量。
- **叶酸**：深色蔬菜、豆类、动物肝 + 补充剂。
- **铁**：首选血红素铁（动物血、肝、红肉），进餐时配富含维生素 C 的蔬果；避免咖啡、浓茶与含铁餐同食。
- **钙**：奶及奶制品是最佳来源；豆制品、深绿色蔬菜、芝麻酱辅助。
- **DHA**：富脂海鱼为主，必要时在医生指导下用 DHA 补充剂。
- **孕吐期**：少量多餐、清淡适口，保证每天至少 130 g 碳水化合物（约 1～2 片面包 + 一小碗饭），预防酮症。

## 常见误区

1. **误区：孕期一人吃两人份，要吃双份。**
   孕早期能量需求与非孕期基本相同，孕中晚期也仅增加约 300 kcal/天，并非"吃两人份"；过量增重反而增加妊娠糖尿病和巨大儿风险。（来源：中国居民膳食指南2022）

2. **误区：叶酸知道怀孕后再补就行。**
   叶酸应从孕前 3 个月开始每天补 400 μg，才能在孕早期达到有效预防神经管畸形的水平；发现怀孕再补已晚于神经管闭合关键期。（来源：中国居民膳食指南2022）

3. **误区：喝奶长胖，用骨头汤补钙。**
   骨头汤钙含量极低（主要是脂肪和嘌呤）；补钙首选奶及奶制品，每天 300～500 mL。（来源：中国居民膳食指南2022）

4. **误区：孕期不能吃海鲜，怕寒凉。**
   指南推荐孕期每周 2～3 次鱼、至少 1 次富脂海鱼以获取 DHA；避免的是大型掠食性鱼类（如鲨鱼、剑鱼）和生鱼。（来源：中国居民膳食指南2022）

5. **误区：哺乳期要大补特补、忌蔬菜水果。**
   哺乳期仅需在平衡膳食基础上增加约优质蛋白和汤水，食物仍应多样；过度油腻浓汤反而堵奶、长胖。（来源：中国居民膳食指南2022）
