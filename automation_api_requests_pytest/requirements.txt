# ============================================================
# 测试依赖 —— 全部锁精确版本
#
# 为什么要锁：
#   CI 每次都是全新环境，不锁版本时 pip 会装"当天最新"的 pytest / 插件。
#   哪天 pytest 或某个插件发了不兼容版本，就会出现"本地绿、CI 红"
#   或者反过来"昨天绿、今天红"，而且和业务代码一点关系都没有。
#   这里的版本取的是本地 .venv 实际跑通过的版本，CI 与本地保持一致。
#
# 升级方式：
#   改版本号 → 本地 pip install -r requirements.txt → 跑一遍 p0
#   → 确认没回归 → 再提交。
#
# ⚠️ 只锁了直接依赖；pytest 的传递依赖（pluggy / iniconfig 等）
#    仍会浮动。要做到完全可复现，用 pip-tools 生成带 hash 的锁文件。
# ============================================================
