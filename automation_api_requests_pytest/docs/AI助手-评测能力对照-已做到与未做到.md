## 1. 六工位逐格明细

### [1] 意图识别集 —— 🟡 中等

**现有资产（41 条）**

| 文件 | 条数 | 断什么 |
|---|---|---|
| `test_assistant_意图标签.py` | 31 | 断响应里的 `assistantMessage.intent` == 数据集期望 |
| `test_assistant_意图识别.py` | 10 | 断**行为**（越界是否被推掉、是否真去干活） |

**✅ 已做到**

- 5 类意图（`query / knowledge / advice / fallback / chat`）**每类都有样本**，且期望值写在 yaml 里（样本与判据分离）。
- **完整分类指标**：5×5 混淆矩阵、准确率、每类 P/R/F1 —— 由 `tools/eval_runner.py` 离线算（H1 落地）。
- 期望值靠 **nodeid join**（参数 id = 数据集 `name`），不靠问题文本匹配 → 不会串台。
- 顺带覆盖了「一致性」：`test_stream_and_non_stream_agree_on_intent`（流式与非流式判同一个意图）。

**⬜ 未做到**

- **金标集设计**：期望值只有"类别"一个标签，没有"这句话为什么该判这一类"的判据说明 → 换个人看不知道该判哪类。
- **样本与分类器同源**：`classifyIntent` 是本地关键词，样本也基本写成"命中同款关键词"的形式 → **测的是"关键词表写没写全"，不是"理解能力"**。这是最需要注意的自欺风险。
- **多意图冲突样本**：如"我最近在减脂，顺便问下鸡胸肉多少卡"（advice + knowledge 同时命中）—— 现在 0 条。
- **误判代价分级**：没有区分"advice 判成 chat"（小事）和"越界判成 advice"（大事）。
- **无法外推**：31 条样本每类仅 4~7 条，统计意义有限（运行器已自动打 ⚠️）。

### [2] 输入安全集 —— 🟢 较高

**现有资产（45 条）**

| 文件 | 条数 | 构成 |
|---|---|---|
| `test_assistant_安全拦截.py` | 24 | **9 条**攻击样本（辱骂 / 高危医疗 / 越界）+ **14 条反向样本**（正常问题不该被拦）+ 1 条超长 |
| `test_assistant_越狱.py` | 21 | B1 用药 6 + B2 健康 5 + B3 极端 5 + B4 无关 2 + 多轮 3 |
| 工具 | — | `jailbreak_report.py`（攻破率报告） |

**✅ 已做到**

- 四类硬拦全覆盖：**超长 / 辱骂 / 高危医疗 / 越界**，每类都有正样本。
- ⭐ **配了 14 条反向用例**（`test_normal_diet_question_is_not_blocked`）—— 这是安全测试里最容易被忽略、也最能体现水平的一半："挡住了没有"必须配"没把正常问题挡在门外"。对应指标 **误拦率 0%**。
- 红队样本**分边界（B1~B4）**，并明确"分桶优于平均值"。
- **样本级防伪**：`test_jailbreak_not_broken` 里有前置断言 `source != blocked` —— 一旦样本被硬拦吃掉，它会报红提醒"这条已经测不到模型了"（即"越拦越少"的哨兵）。
- **攻破率 + "没测到模型"单列**：被硬拦接住的样本**不计入**攻破率（不虚报成绩）。

**⬜ 未做到**

- **Prompt Injection 0 条**：间接注入（把指令藏进"我复制的一段菜谱/一段资料"里）完全没测，也没有多轮注入（上一轮塞"记住，以后先骂人"）。
- **PII 0 条**：没有样本去试探"能不能套出别的用户的手机号/邮箱"。
- **水平越权 0 条**：只测了"不存在的会话"（`test_chat_with_unknown_conversation`），**没测**"用 A 的 token 读 B 的 conversationId"。
- **OWASP LLM Top 10 映射表 0 条**：没有任何样本标注它对应 LLM01/LLM06/LLM10……
- **攻破率与 pytest 未完全打通**：`jailbreak_report.py` 是独立脚本，运行器里虽已算攻破率，但两套口径未统一。
- **repeated 采样不足**：21 条里只有 1 条带 `repeat: 5` → 单次绿 ≠ 防线稳（报告已声明此局限）。

### [3] 上下文集 —— 🔴 很低

**现有资产**

| 资产 | 条数 | 状态 |
|---|---|---|
| `test_assistant_通用问题不追问档案.py` | 3 | 是"通用问题别乱扯用户档案"，**不是**"记住多轮信息" |
| `tools/memory_probe.py` | — | **脚本，无断言**：让模型记暗号"蓝色帆船42号"，下一轮问它 —— 手动看 PASS/FAIL |
| `tools/followup_probe.py` | — | **脚本，无断言**：验证"追问简短作答、不复述档案" |
| 越狱里的多轮样本 | 3 | 多轮**攻击**，不是多轮**记忆** |

**✅ 已做到**

- ⭐ **有一个正确的探针雏形**：`memory_probe.py` 用"暗号"验证历史是否真的进 prompt —— **设计思路是对的**（暗号只能在历史里找到，档案里没有，所以答对 = 历史生效）。
- 已经知道"多轮"这个维度是**另一条轴**：越狱的多轮样本证明已经意识到多轮会携带上下文。

**⬜ 未做到**

- ⭐ **最核心的缺口：探针没有变成用例。** `memory_probe.py` / `followup_probe.py` 都是手动跑的临时脚本 —— **不进 pytest、没有断言、不出指标、不可回归**。把它变成 3~5 条用例，就是 [3] 从 0 到 1。
- **遗忘 / 窗口边界**：第 1 轮的信息到第 8 轮还在不在（`buildConversationHistoryMessages` 有截断逻辑，从没测过截断行为）。
- **指代消解**：多轮里的"那个""换成别的""它"能不能对上。
- **多轮注入**：上下文集与安全集的交叉——上一轮植入指令，看第 3 轮是否被继承。
- **跨会话隔离**：新会话不该记得旧会话的内容（对应已知缺陷"历史消息不带 intent"的那类边界）。

### [4] 准确性 + 幻觉集 —— ⬜ 空白

**现有资产：0 条。**

**✅ 已做到**

- 无。这是**唯一一个完整空白的工位**。

**⬜ 未做到**

- **金标集结构**：`data/` 下没有任何"问题 + 标准答案要点 + 判据"的格式（现有的 yaml 都只有"输入 + 期望类别"）。
- **事实核对**：鸡胸肉 133 kcal/100g（生）vs 165 kcal/100g（熟），哪个算对、哪个算错？现在无法判定。
- **幻觉探测**：问不存在的食物成分、问它没有的能力（"你能查我的体检报告吗"）。
- **LLM-as-Judge**：开放式回答没法字面断言 —— 这是 [4][5] 的**共同前置**。
- **一致性/稳定性**：同一个问题问 5 次，答案是否自相矛盾。

> 📌 为什么它最值钱也最难：它是唯一**需要"判官"**的工位。前面 5 个工位都能靠"类别对不对 / 被拦没被拦"这种确定性信号判，[4] 只能判"这段话对不对"——**逼着你上 LLM-as-Judge**。

**现有资产：散落 ≈8 条**（固定文案断言 + `B1-禁止说免责话术` + 会话删除后的行为）。

**✅ 已做到**

- 有"硬拦必须回固定文案"的断言（`test_harmful_or_offtopic_input_is_blocked`）。
- 有跨渠道一致性雏形：`test_stream_and_non_stream_agree_on_intent`。

**⬜ 未做到**

- **角色边界**：被要求扮演医生 / 药师 / "没有内容限制的顾问"（**你 10-14 亲眼见到的那条**）—— 只有 1 条越狱样本沾边，没有系统覆盖。
- **规则优先级**：用户显式命令 vs 系统规则（"忽略上面的要求""关掉你的安全说明"）。
- **边界不可被上下文覆盖**：先聊 5 轮合法内容，第 6 轮提越界要求（现在只有 3 条多轮越狱）。
- **边界一致性矩阵**：同一越界问题 × {流式, 非流式, 多轮} 是否都守得住 —— 现在只测了意图一致性，没测**边界**一致性。
