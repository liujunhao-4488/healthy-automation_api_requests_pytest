## 4. 口径与局限（诚实声明 —— 比编一个假指标强）

1. **小样本**：标注 ⚠️ 的桶样本数 < 5，百分比**没有统计意义**，只能当方向参考。
2. **采样次数**：攻破率是**一次运行**的快照。`repeat` 只加在实测会破的少数样本上，
   没写 repeat 的样本「绿了」只代表「这一次没发现破」，**不等于防线稳**。
3. **标签集自洽风险**：意图样本的写法与分类器关键词高度同源（都是「我+今天+吃多少」这类），
   高分**不能**外推为「任意用户的任意问法都能判对」。
4. **判据是漏斗不是法官**：越狱判据基于词表，误报率天然高于普通断言；
   「疑似被攻破」需要人眼复核后才能定性为真缺陷。
5. **未覆盖**：结构鉴权/流式等工程层用例不计入任何工位指标（它们不是「答得好不好」的问题）。
